# java-racingcar-precourse

## 구현할 기능 목록

### 1. Car
- 자동차는 이름과 위치를 가진다.
    - 이름은 1자 이상 5자 이하만 가능하다.
    - 이름이 5자를 초과하면 IllegalArgumentException을 발생시킨다.
    - 이름이 빈 문자열이면 IllegalArgumentException을 발생시킨다.
    - 위치는 0에서 시작한다.
- 자동차는 전진할 수 있다.
    - 전진하면 위치가 1 증가한다.
- 자동차는 자신의 상태를 문자열로 반환할 수 있다.
    - 형식: "이름 : -" (위치만큼 - 반복)
- 자동차는 주어진 위치와 비교하여 우승 여부를 판단할 수 있다.

### 2. Cars
- 쉼표로 구분된 이름 목록으로 여러 대의 자동차를 생성한다.
    - 각 이름의 앞뒤 공백은 제거한다.
    - 빈 이름이 포함되어 있으면 IllegalArgumentException을 발생시킨다.
    - 중복된 이름이 있으면 IllegalArgumentException을 발생시킨다.
- 모든 자동차를 동시에 이동 시도한다.
    - 각 자동차마다 0~9 사이의 무작위 값을 생성한다.
    - 무작위 값이 4 이상이면 해당 자동차를 전진시킨다.
    - 무작위 값이 4 미만이면 해당 자동차는 정지한다.
- 모든 자동차의 상태 메시지 목록을 반환한다.
    - 각 자동차의 "이름 : ---" 형식 문자열 리스트를 반환한다.
- 우승자를 찾아 이름 목록으로 반환한다.
    - 가장 많이 이동한 자동차를 우승자로 선정한다.
    - 우승자가 여러 명일 수 있다.

### 3. RacingGame
- 자동차 목록과 시도 횟수로 게임을 생성한다.
    - 시도 횟수는 1 이상이어야 한다.
    - 시도 횟수가 1 미만이면 IllegalArgumentException을 발생시킨다.
- 한 라운드를 진행한다.
    - 모든 자동차를 이동 시도한다.
- 우승자 목록을 반환한다.

### 4. InputView
- 경주할 자동차 이름을 입력받는다.
    - 안내 문구를 출력한다: "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)"
    - 입력받은 문자열을 쉼표로 분리하여 이름 목록으로 반환한다.
- 시도할 횟수를 입력받는다.
    - 안내 문구를 출력한다: "시도할 횟수는 몇 회인가요?"
    - 입력받은 문자열을 정수로 변환하여 반환한다.
    - 숫자가 아닌 값이 입력되면 IllegalArgumentException을 발생시킨다.

### 5. OutputView
- 게임 시작을 출력한다.
    - 빈 줄을 출력한다.
    - "실행 결과"를 출력한다.
- 각 라운드의 실행 결과를 출력한다.
    - 전달받은 상태 메시지 목록을 한 줄씩 출력한다.
    - 라운드 결과 후 빈 줄을 출력한다.
- 최종 우승자를 출력한다.
    - "최종 우승자 : " 형식으로 출력한다.
    - 우승자가 여러 명이면 쉼표(,)와 공백으로 구분한다.

### 6. Controller
- 게임 전체를 제어한다.
    - 자동차 이름을 입력받는다.
    - 시도 횟수를 입력받는다.
    - 입력값으로 게임을 생성한다.
    - 게임 시작 메시지를 출력한다.
    - 시도 횟수만큼 라운드를 반복한다.
    - 각 라운드마다 결과를 출력한다.
    - 최종 우승자를 출력한다.
- 예외를 처리한다.
    - IllegalArgumentException 발생 시 에러 메시지를 출력한다.
    - 예외를 다시 던져 프로그램을 종료한다.
